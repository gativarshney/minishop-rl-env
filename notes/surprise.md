I expected the popups to hurt the Q-learning agent, and I expected its success rate to fall as popup_p went from 0 to 0.4. It did not: the agent succeeded in 210 of 210 evaluation attempts at popup_p 0, 0.15 and 0.4, and only the mean number of steps changed, from 4.30 to 5.02. My explanation is that this page is easy for a table: the state is relative to the goal and the View:goal action says which product to open, so there is little to learn except to dismiss popups and to wait for delayed buttons (0.31 waits per attempt at popup_p 0). A popup only costs one Dismiss click, which fits the extra 0.7 steps, and the 20 step limit is far away. The random agent succeeded in only 6 of 210 attempts, so the task is not trivial without learning. I trust the 100% for this page, but it is too easy to tell the three popup levels apart by success rate, so it says little about harder pages.
