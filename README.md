# MiniShop RL Env

RL environment for a simulated shopping webpage, controlled via CDP.

## Setup
- Windows: Run `.\run.ps1`
- Linux: Run `./run.sh`

Requires CMake, C++ compiler, Python 3, and Chromium/Chrome.

## Pending Parts
- Full parallel execution is not implemented.
- The Q-learning table is sparse, and the loop in `run_all.py` is minimal.
